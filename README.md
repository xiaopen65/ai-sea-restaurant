# 新版 · 漂流的海上餐厅（AI 航海研习社）

十五关全量铺开版（序幕 + 第1–15幕）。

## 现在有什么
- 出海前：选性别（男 / 女各 4 个头像）、填名字
- 横版地图：木牌关卡（只有编号，不带标题）、虚线航线、顶部进度条
- HUD 分布：左上角玩家卡片（头像 + 名字）、右上角进度 + 背包 + 设置、左下角标题、右下角图例
  - 点左上角那张卡片 → 弹「改个名字」，改完地图和对话里的称呼一起换（原来那行写死的"无名号"已经去掉了）
  - 底部的提示条平时是空的（不占视线），只有"这块木牌还没亮""自由探索已打开"这类提醒才出现，3 秒后自己消失
- 点木牌 → 一句一行推进的对话（打字机 12ms/字、点击继续）
  - 旁白没人头像；阿财 / 你 / 客人说话都带头像和名字
  - 右上角两个按钮：看完整剧情（可折叠，文字可复制）、跳过
- 剧情演完 → 任务卡，分两屏：
  - 第一屏（封面）：只有「第 N 关：完成一次 ×××」+ 一两句简介 + 一颗满宽「开始行动」
  - 第二屏（行动）：点「开始行动」才展开 —— 这次要做什么 / 行动步骤（默认折叠，卡住了再看）/ 课程锦囊 / 任务反馈
  - 卡里正文可以选中复制
  - 还没交反馈：底部只有一颗贴在右下角的**完成提交**；反馈必须交（文字有最少字数，第 3 关要传海报）才算通关
  - 交过之后：底部换成左下「查看剧情」（整段铺开，不用一句一句点）+ 右下「查看背包」；**不再回显交上去的东西**，要看去背包
  - 右上角一个 × ：先收起来，这一关不算完成，回头再点木牌还能接着做
- 课程锦囊是单独一个小弹窗：课程名 + 一句介绍 +「去看这门课」（新窗口打开）
- 已经走完的关，再点木牌**不再重放剧情**，直接把行动页摊开；想看当时那段，点卡里的「查看剧情」
- 点「完成提交」→ 接完成反馈对话 → 结算横幅 → 地图上这一关变绿打勾
  - 横幅里会多一行「拿到手了 —— ×××（已放进背包）」
- 右上角「背包」：15 个格子，走过一关点亮一件，点格子看它是什么、是哪一关留下的
  - 详情里把**当初交的反馈**原样摆出来（带一行「X 月 X 日交的」），左下角一颗「编辑」可以改：文字关改字，图片关换图
  - 角标 = 没看过的东西有几件：刚拿到就亮，打开背包看过就消失
  - 打开时没看过的格子左上角挂个金色「新」，这一次看过，下次打开就没了
- 右上角「设置」：背景音乐 + 音效 + 自由探索开关 + 重新开始（重来会先弹窗确认，不会一点就清档）
  - 四行只留标题和控件，说明文字已去掉
  - 背景音乐 / 音效各有「开 / 关」+ 一条音量条；关掉时音量条自动变灰
  - 音乐是"一进来先不出声，你点第一下才开始"——绕不过浏览器的自动播放限制，这是正常的
- 声音全部是**现场合成的像素音**，一个音频文件都没有：
  - 背景音乐：16 小节循环（贝斯 + 琶音 + 主旋律 + 轻鼓），104 BPM，方波/三角波的芯片味
  - 音效：点按钮「嗒」、翻木牌上滑、交卷一小段上行音、拿到东西叮一下、点没解锁的牌子低响一声
  - 有弹窗 / 对话盖在地图上时，音乐会自动压低一档，收起来再回来
  - 开关和音量都进存档，下次进来还是你上次的设置
- 第5幕走完之前，外海（第6–15幕）不显示，右半边是雾；走完自动展开
- 序幕没有任务，只放背景；不计入 15 关进度
- 手机竖屏：**不挡着**，整个画面顺时针转 90° 显示，中间飘一句「把手机往左转一下」，5 秒后自己淡掉
  - 这样就算手机开了「竖屏锁定」，把手机往左一转，看到的正好是正的
  - 转成横屏就自动恢复正常方向，不用刷新

## 手机上怎么显示
横屏手机（屏幕净高只剩 330~480px）：走 `html.is-short` / `html.is-tiny` 两档自动收紧，
弹窗一律 `max-height` + 内部滚动，底部那颗按钮 sticky 贴在弹窗底边，不会再把"开始航行 / 收起来"顶出屏幕。

竖屏手机：整个画面顺时针转 90°（`html.is-flip`）。用户真把手机转过去之后浏览器会报横屏，
`is-flip` 自动摘掉，就是正常的横屏画面。

转屏提示（`#rotateHint`）**故意放在 `<div class="rot">` 外面** —— 放在里面会跟着一起转，竖屏看就是歪的。
放在外面它才是正的，竖屏拿起来就能读。它 `pointer-events: none`，不挡点击，5 秒后自己淡掉。

竖屏打字（`html.is-typing`）：画面转了 90°，可手机键盘永远是竖的。所以输入框一拿到焦点，
就把手里那块弹窗反向转回来（`transform: rotate(-90deg)`）+ 挪到屏幕上边，让"框里的字"和"键盘"同一个方向。
失焦就转回去。起名字那屏和改名字弹窗都吃这条规则。

### 文字格宽度：一律用 JS 写死 px（手机上的折行 bug）

有些手机浏览器（荣耀 / 华为那类内核）会把**弹性子项**的宽度按「文字固有宽度」缓存住，
字体换好、文字变长之后它不重算 —— 表现就是旁白在弹窗中间折行、右边空一大块。
桌面 Chrome 复现不出来，所以不能靠 % 或 flex 去猜。

app.js 里的 fitTextCol(box, col, face)：每次换行 / resize / 转屏 / 字体加载完都量一遍盒子，
把文字格宽度写成具体 px（width + min-width + flex-basis 三重一起写）。
挂了三处：对话条（#dlgMain）、剧情回顾（.sline__box）、背包详情（.bag__dmain）。
以后新加「头像 + 文字」的横排结构，都要挂一次 fitTextCol。


船名（漂流的海上餐厅 / AI 航海研习社）原来挂在 HUD 左下角，现在搬进了「点头像」的名牌弹窗里
（`#profile` 里的 `.profile__brand` / `.profile__sub`）。

⚠️ 三个坑，以后改样式别踩：
1. 竖屏翻转时，物理的 `vw / vh` 跟画面实际宽高是**对调**的。样式里不要直接用 `vw / vh`，
   要用 `--pw` / `--ph`（app.js 每次 resize 都会把精确 px 写进这两个变量）：
       width: min(620px, calc(var(--pw) * .92));
       max-height: calc(var(--ph) * .86);
2. 同理 `@media (max-height: ...)` 在竖屏翻转时量不到真正的画面高度，矮屏请用 `html.is-short` / `html.is-tiny`。
3. 装文字的 flex 子项（`.dlg__main` / `.sline__box`）别只写 `flex: 1`。
   `flex: 1` 的 flex-basis 是 0%，这一格的宽度会由「内容固有宽度」决定；网页字体 zpix 还没加载完时
   算出来的宽度偏窄，字体换好之后**有些手机不会重算**，文字就会在弹窗中间突然折行、右边空一大块。
   现在写成 `flex: 1 1 100%; width: 100%; min-width: 0`，宽度直接跟盒子走；另外 `<head>` 里 preload 了
   zpix，`document.fonts.ready` 之后再 `applyFlip()` 一次兜底。

## 任务卡的数据长什么样（data/acts.js）

每一关除了 `story`（剧情）和 `feedback`（反馈），还有一个 `quest` 字段。
**没写 `quest` 的关卡**会拿老的 `goal / steps / tips` 兜一份，不会白屏 —— 但兜出来的标题是
「完成一次「关卡名」」，话说不清楚，所以十五关都应该写自己的 `quest`。

    quest: {
      title: "完成一次和 AI 的“自我盘点”对话",   // 封面标题，前面会自动加「第 N 关：」
      lead:  ["一两句简介，封面只放这个"],        // 别写长，1–2 行就够
      brief: ["点「开始行动」之后才出现的具体指令，一行一段"],
      steps: ["行动步骤，默认折叠，卡住了再看"],
      tip:   { name: "课程名", about: "一句介绍", url: "https://..." },
      report:{ kind: "text", ask: "把 ×× 贴进来。", hint: "小字提示", min: 10 }
    }

`report.kind` 两种：`"text"` 交一段文字（`min` 是最少几个字）；`"image"` 交一张图（第 3 关做海报），传上来才让交。
交上去的东西存在 `state.report[id] = { at, text?, img? }`，背包的「编辑」和「X 月 X 日交的」都读它。

## 换图 / 换头像以后
app.js 顶部有 `var ASSET_V = "7";`，改完 assets 里的图把这个数字 +1，
浏览器就不会继续用缓存里的旧图。头像和地图都走这个版本号。

## 头像渲染说明
人物头像是 256 原图，`image-rendering: auto`（平滑）才清晰；
地图、UI 走 `img { image-rendering: pixelated }`，保持像素风。
修改后如果浏览器还显示旧图，用 Ctrl+Shift+R 强制刷新一次（index.html 本身也会被缓存）。

## 存档
浏览器 localStorage，键名 sea-restaurant-v3。右上角"重来"可清空。
里面 `report` 存每一关交的反馈，`seen` 存背包角标看没看过。

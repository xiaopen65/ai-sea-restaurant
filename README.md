# 新版 · 漂流的海上餐厅（AI 航海研习社）

十五关全量铺开版（序幕 + 第1–15幕）。

## 现在有什么
- 出海前：选性别（男 / 女各 4 个头像）、填名字
- 横版地图：木牌关卡（只有编号，不带标题）、虚线航线、顶部进度条
- HUD 分布：左上角玩家卡片（头像 + 名字）、右上角进度 + 背包 + 设置、左下角标题、右下角图例
  - 点左上角那张卡片 → 弹「改个名字」，改完地图和对话里的称呼一起换（原来那行写死的"无名号"已经去掉了）
  - 底部的提示条平时是空的（不占视线），只有"这块木牌还没亮""自由探索已打开"这类提醒才出现，3 秒后自己消失
- 点木牌 → 一句一行推进的对话（打字机 12ms/字、点击继续）
  - 旁白没人头像；阿财 / 你 / 客人说话都带头像和名字
  - 右上角两个按钮：看完整剧情（可折叠，文字可复制）、跳过
- 剧情演完 → 任务卡（目标 + 行动步骤 + 打开锦囊），卡里的文字可以选中复制
  - 第3幕（做海报）多一个上传按钮，传了海报才能交卷
  - 还没走完：底部只有一颗**我做完了**，贴在右下角
  - 走完之后：交卷键收起来，换成左下「查看剧情」（整段铺开，不用一句一句点）+ 右下「查看背包」
  - 右上角一个 × ：先收起来，这一关不算完成，回头再点木牌还能接着做
- 已经走完的关，再点木牌**不再重放剧情**，直接把任务卡摊开；想看当时那段，点卡里的「查看剧情」
- 点"我做完了" → 接完成反馈对话 → 结算横幅 → 地图上这一关变绿打勾
  - 横幅里会多一行「拿到手了 —— ×××（已放进背包）」
- 右上角「背包」：15 个格子，走过一关点亮一件，点格子看它是什么、是哪一关留下的
  - 角标 = 没看过的东西有几件：刚拿到就亮，打开背包看过就消失
  - 打开时没看过的格子左上角挂个金色「新」，这一次看过，下次打开就没了
- 右上角「设置」：背景音乐 + 音效 + 自由探索开关 + 重新开始（重来会先弹窗确认，不会一点就清档）
  - 四行只留标题和控件，说明文字已去掉
  - 背景音乐 / 音效各有「开 / 关」+ 一条音量条；关掉时音量条自动变灰
  - 音乐是"一进来先不出声，你点第一下才开始"——绕不过浏览器的自动播放限制，这是正常的
- 声音全部是**现场合成的像素音**，一个音频文件都没有：
  - 背景音乐：16 小节循环（贝斯 + 琶音 + 主旋律 + 轻鼓），104 BPM，方波/三角波的芯片味
  - 音效：点按钮「嗒」、翻木牌上滑、交卷一小段上行音、拿到东西叮一下、点没解锁的牌子低响一声
  - 有弹窗 / 对话盖在地图上时，音乐会自动压低一档，收起来再回来
  - 开关和音量都进存档，下次进来还是你上次的设置
- 第5幕走完之前，外海（第6–15幕）不显示，右半边是雾；走完自动展开
- 序幕没有任务，只放背景；不计入 15 关进度
- 手机竖屏：**不挡着**，整个画面顺时针转 90° 显示，中间飘一句「把手机往左转一下」，5 秒后自己淡掉
  - 这样就算手机开了「竖屏锁定」，把手机往左一转，看到的正好是正的
  - 转成横屏就自动恢复正常方向，不用刷新

## 怎么看
方式一（推荐，像素字体才会生效）：在"新版"目录起个本地服务，浏览器打开
    python -m http.server 8765
    http://127.0.0.1:8765/index.html

方式二：直接双击 index.html（能用，但像素字体在 file:// 下会被浏览器拦掉，会退成系统字体）

## 预览钩子（做图、验收用）
    index.html?stage=dialog&act=7&line=8   直接看第7幕第 8 行
    index.html?stage=full&act=13           打开"看完整剧情"
    index.html?stage=task&act=3            直接看任务卡
    index.html?stage=taskdone&act=3        直接看"已完成"状态的任务卡
    index.html?stage=story&act=1           直接看剧情回顾（整段铺开）
    &audiodebug=1                          把当前声音状态写到 <html data-audio="...">，调声音时看这个
    &flip=1                                强制竖屏那种"整体转 90°"的模式，方便在电脑上验
    index.html?stage=fb&act=5              直接看完成反馈
    index.html?stage=done&act=15&closefog=1  全部通关的地图
    （任意预览钩子后面都可以加 &fresh=1，每次都从零开始，不吃上次的存档）

## 文件
    index.html        页面结构
    styles.css        全部样式（像素风）
    audio.js          音乐与音效（Web Audio 现场合成，不带音频文件）
    app.js            交互逻辑（对话推进、任务、上传、存档）
    data/items.js     背包物品：15 件的名字 + 16×16 像素图标（用方块拼的，不依赖图片）
    data/acts.js      内容数据：16 幕（0 序幕 + 15 关）的剧情切分、任务、反馈、锦囊
                      同时管着关卡在地图上的坐标 map: { x, y }
    assets/           头像、像素字体、地图底图
    preview/          这一轮的截图（12/13/14 设置面板、重来确认、顶部 HUD；15/16/16b/16c 物品横幅与背包）

内容这一版只从 xlsx 搬进来 + 切分，没有改写。要改文字直接改 data/acts.js 里的
「n / a / y / g1…」那几行就行，一行 = 屏幕上一句。

## 换图 / 换头像以后
app.js 顶部有 `var ASSET_V = "7";`，改完 assets 里的图把这个数字 +1，
浏览器就不会继续用缓存里的旧图。头像和地图都走这个版本号。

## 头像渲染说明
人物头像是 256 原图，`image-rendering: auto`（平滑）才清晰；
地图、UI 走 `img { image-rendering: pixelated }`，保持像素风。
修改后如果浏览器还显示旧图，用 Ctrl+Shift+R 强制刷新一次（index.html 本身也会被缓存）。
